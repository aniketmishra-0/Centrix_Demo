Operational Guide

How to Use Centrix

Zero learning curve for teachers — 100% automated background execution.

Setup Time: < 2 Minutes • User Action Required: Zero
01 One-Time Setup

Install & Bind Google JSON

Run Centrix-Setup.exe on the classroom PC. Select center and room. Provide the Google Cloud google_credentials.json desktop client file to bind Drive & YouTube via 1-click browser sign-in with Windows DPAPI hardware encryption.

Zero Hardcoded Secrets • DPAPI Vault
02 Faculty Workflow

Teach in OBS & Export Notes

Faculty and operators teach normally! Start the lecture in OBS Studio, conduct class, and click "Stop Recording". Export MaxHub smartboard notes to .pdf—Centrix pairs both automatically with zero extra faculty effort.

Zero disruption to teachers
03 Autonomous Core

7-Signal Match & Upload

Centrix enforces a 10s stability lock, runs the deterministic 7-signal timetable match, standardizes file naming, and auto-uploads 10MB resumable chunks directly to Google Drive & YouTube.

≥ 85% Confidence Auto-passes
04 Internal Pipeline

Drive ➔ YouTube Pipeline

Lectures and notes sync to Google Drive in < 30 minutes and queue for YouTube. Coordinators monitor all rooms live via localhost:5200 with 1-click review for ambiguous overtime sessions.

Internal Turnaround SLA < 30 Mins
